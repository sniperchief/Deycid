DEYCID
An intelligence decision layer for autonomous agents. It buys verified intelligence from the Telegraph network until a decision reaches its confidence target — or its budget runs out.

Confidence is Deycid confidence — computed by Deycid from observable properties of each Telegraph exchange. Telegraph returns no per-response confidence score. Every “verify” link opens the public Telegraph record of that call.
for developers — run it yourself
Deycid is an MCP server. Add it to Claude Desktop, Cursor, or any MCP client and your assistant can call it before acting on-chain — paying from your own wallet.
{
  "mcpServers": {
    "deycid": {
      "command": "npx",
      "args": ["-y", "github:sniperchief/Deycid"],
      "env": { "AGENT_PRIVATE_KEY": "0x<burner key>" }
    }
  }
}
Fund the wallet with Base Sepolia USDC from faucet.circle.com — no testnet ETH needed, the facilitator pays gas. Source and docs: github.com/sniperchief/Deycid.
